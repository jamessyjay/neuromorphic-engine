# Hardware Target & Hybrid Tech Stack

## 1. Целевая Платформа
* **Оборудование:** NVIDIA Jetson Orin Nano (8GB RAM).
* **Особенности:** 1024 ядра CUDA (Ampere), 6-ядерный CPU ARM Cortex-A78AE, **Unified Memory** (Общая память между CPU и GPU, отсутствие необходимости копировать данные туда-сюда).

## 2. Гибридный Стек (Rust + C++/CUDA)
Проект использует гибридную архитектуру для достижения максимальной безопасности и скорости.
* **Rust (Host / CPU):** Отвечает за класс `Environment`, отсчет тактов (Tick System), сеть, логирование и управление жизненным циклом программы.
* **C++ / CUDA C (Device / GPU):** Отвечает ИСКЛЮЧИТЕЛЬНО за параллельную математику нейронов (Leak, Calcium, Spike, Weights update).

## 3. Архитектура взаимодействия (FFI)

* **Unified Memory:** Массив состояний всех нейронов (заряды, таймеры, химия) аллоцируется в Rust с использованием CUDA Unified Memory (`cudaMallocManaged` через FFI). Оба языка смотрят в один и тот же кусок физической памяти.
* **Вызов ядер (Kernels):** На каждом тике Rust вызывает функцию C++ (через `extern "C"`), которая запускает `__global__` ядро на GPU для параллельного пересчета всех 1024+ нейронов.

## 4. Задача Агента (КРИТИЧЕСКИ ВАЖНО)
Ведущий разработчик (человек) фокусируется на архитектуре в Rust. 
Твоя задача (ИИ-агента) — брать на себя всю тяжелую работу по написанию **C++/CUDA кода**.
1. Ты обязан предоставлять готовые `.cu` файлы с логикой нейрона.
2. Ты обязан предоставлять C-header файлы (`.h`) для связки.
3. Ты обязан генерировать Rust-обертки (через `bindgen` или руками `extern "C"`) и скрипты `build.rs`, чтобы Rust мог бесшовно скомпилировать и вызвать твой CUDA-код.
